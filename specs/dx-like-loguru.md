# Developer Experience improvement

This repo was built up for some concrete logging needs for real projects.
I'd like to think more broadly.
How can we improve the overall developer experience
so that it would be useful for any Forge developer.

For inspiration, consider:
https://loguru.readthedocs.io/en/stable/overview.html#features

That's a Python logging library,
so not everything there would work in Node or Forge.
For example, there's no need for colors,
given the log viewer in the developer console or the Forge CLI.
However, I think the features described
could inspire us in some developer experience improvements for this library.

I want you to analyze loguru's features,
compare them to what already exists here,
and propose a set of prioritized feature improvements.
